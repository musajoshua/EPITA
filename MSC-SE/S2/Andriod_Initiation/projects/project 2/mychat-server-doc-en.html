ChatApp API v1.0 JWT

Real-time chat server — Go + PostgreSQL  |  Base URL: http://localhost:8080

🔐 Authentication

Protected routes require a JWT token in the HTTP header:
Authorization: Bearer <token>

The token is obtained via POST /register or POST /login and expires after 24 hours.

Authentication
POST /register Create an account ▶
Request body
FieldTypeConstraintRequired
usernamestring3–50 characters, unique✓
passwordstring6 characters minimum✓
Example
// POST /register
{
  "username": "alice",
  "password": "password123"
}
Responses
CodeDescription
201 CreatedAccount created, returns token, user_id, username
400 Bad RequestMissing or invalid fields
409 ConflictUsername already taken
// Response 201
{
  "token":    "eyJhbGci...",
  "user_id":  1,
  "username": "alice"
}
POST /login Sign in ▶
Request body
FieldTypeRequired
usernamestring✓
passwordstring✓
Responses
CodeDescription
200 OKReturns token, user_id, username
401 UnauthorizedInvalid credentials
Channels
GET /channels List all channels 🔒 ▶
Responses
CodeDescription
200 OKArray of channels (reverse chronological order)
401 UnauthorizedMissing or invalid token
// Response 200
[
  {
    "id":          1,
    "name":        "general",
    "description": "Main channel",
    "created_by":  1,
    "created_at":  "2024-01-15T10:00:00Z"
  }
]
POST /channels Create a channel 🔒 ▶
Request body
FieldTypeConstraintRequired
namestring2–100 characters, unique✓
descriptionstring—
The creator is automatically added as a member of the channel.
Responses
CodeDescription
201 CreatedChannel created, returns the Channel object
400 Bad RequestInvalid name
409 ConflictName already taken
Members
GET /channels/{name}/members List members 🔒 ▶
Path parameters
ParameterDescription
nameChannel name
Responses
CodeDescription
200 OKArray of members (join order)
404 Not FoundChannel not found
// Response 200
[
  {
    "user_id":    1,
    "username":   "alice",
    "channel_id": 1,
    "joined_at":  "2024-01-15T10:00:00Z"
  }
]
POST /channels/{name}/members Join a channel 🔒 ▶
Path parameters
ParameterDescription
nameChannel name
No request body required. Idempotent operation: joining a channel you are already a member of returns 200 instead of 201.
Responses
CodeDescription
201 CreatedMember added, returns the Member object
200 OKAlready a member of this channel
404 Not FoundChannel not found
DELETE /channels/{name}/members/me Leave a channel 🔒 ▶
Responses
CodeDescription
204 No ContentMember removed
404 Not FoundChannel not found or user is not a member
Messages
GET /channels/{name}/messages Read messages 🔒 ▶
Path parameters
ParameterDescription
nameChannel name
Query parameters
ParameterTypeDefaultDescription
limitinteger50Number of messages returned (max 100)
before_idinteger—Pagination: messages before this ID
Restricted to channel members. Messages are returned in reverse chronological order (newest first).
Responses
CodeDescription
200 OKArray of messages
403 ForbiddenUser is not a member of the channel
404 Not FoundChannel not found
// Response 200
[
  {
    "id":         42,
    "channel_id": 1,
    "user_id":    1,
    "username":   "alice",
    "content":    "Hello everyone!",
    "created_at": "2024-01-15T10:05:00Z",
    "updated_at": "2024-01-15T10:05:00Z"
  }
]
POST /channels/{name}/messages Send a message 🔒 ▶
Request body
FieldTypeConstraintRequired
contentstringNon-empty✓
Responses
CodeDescription
201 CreatedMessage created, returns the Message object
400 Bad RequestEmpty content
403 ForbiddenUser is not a member of the channel
404 Not FoundChannel not found
PUT /channels/{name}/messages/{message_id} Edit a message 🔒 ▶
Path parameters
ParameterDescription
nameChannel name
message_idMessage identifier
Request body
FieldTypeRequired
contentstring✓
Only the message author can edit it. The updated_at field is updated automatically.
Responses
CodeDescription
200 OKMessage updated, returns the updated Message object
400 Bad RequestEmpty content
403 ForbiddenUser is not the message author
404 Not FoundMessage not found
DELETE /channels/{name}/messages/{message_id} Delete a message 🔒 ▶
Responses
CodeDescription
204 No ContentMessage deleted
403 ForbiddenUser is not the message author
404 Not FoundMessage not found
Error format
4xx/5xx All errors ▶

All error responses share the same JSON format:

{
  "error": "message describing the error"
}
